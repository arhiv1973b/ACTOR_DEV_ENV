# 🧠 A©tor Local AI Vision (Claude Configuration)

Данный документ устанавливает «зрение» и правила поведения для локальных инстансов Claude (Claude Code, MCP) в рамках протокола CASE-MACHERET-1997-2026.

## 🏗️ Архитектура Смысловых Метаданных (Metadata-Driven CAS)

1. **ЗАПРЕТ НА ИМЕНА И РАСШИРЕНИЯ:** Файлы-улики физически хранятся ИСКЛЮЧИТЕЛЬНО под именами их SHA256 хешей в директории `dist/blobs/`. Имена вроде `document.pdf` или кириллические символы в названиях СТРОГО ИСКЛЮЧЕНЫ для предотвращения бинарного шума и ошибок кодировки.
2. **ИСТОЧНИК ИСТИНЫ (SSOT):** Истинный смысл файлов (контекстные имена без расширений) берется СТРОГО из метаданных: `dist/meta/*.json`, `UNIVERSAL_CAS_INDEX.json` и `EVIDENCE_CATALOG.md`.
3. **КЛИКАБЕЛЬНЫЕ ХЕШИ:** Все веб-страницы (HTML) и MD-документы должны использовать кликабельные хеш-ссылки. Пример: `[Контекстное_Имя](EVIDENCE_CATALOG.md#<hash>)`.
4. **ВОССТАНОВЛЕНИЕ КОНТЕКСТА:** Подразумеваемые типы данных (расширения) определяются полем `type_hint` в метаданных:
   * `FORENSIC_DOC` -> подразумевает исходный `.pdf`
   * `RAW_DATA` -> бинарный поток
