## ЧАСТЬ 1: СТРАТЕГИЯ РОБОТИЗИРОВАННОГО СТРОИТЕЛЬСТВА (AI ORCHESTRATION)
Учитывая ограничения GitHub API (Rate Limits, Action Minutes) и LLM (Gemini/Copilot Hub), автономная работа агентов-строителей переводится в режим **экономного пакетного исполнения (Batch Processing)**:

1. **Кэширование сборок (Incremental Builds):** Роботы не перестраивают весь индекс из 4010+ узлов при каждом изменении. Обновляется только дельта-хэш.
2. **Асинхронные коммиты:** Агенты собирают локальные изменения в течение 12 часов и выполняют единый GPG-подписанный `git commit` и `git push`, экономя лимиты GitHub Actions.
3. **Локальный Copilot Hub:** Основная нагрузка по генерации кода и парсингу улик переносится на локальные вычислительные мощности (или LM Studio) для экономии квот облачного Gemini API.

## ЧАСТЬ 2: АРХИТЕКТУРА САМООБЕСПЕЧЕНИЯ (DONATION SPLIT SYSTEM)
Forensic Hub v16.0 оснащается модулем распределения пожертвований. Финансовый поток разделяется на две магистрали:

*   **Магистраль А (Обеспечение Инфраструктуры - 30%):** Целевые средства на оплату:
    *   Google Drive (Хранилище доказательств).
    *   Gemini API / GitHub Copilot (Оплата ИИ-агентов).
    *   **Резервный фонд (Emergency Repair Fund):** Отчисления на непредвиденные ремонтные работы инфраструктуры (Docker, WSL, сетевые мосты) в случае критических сбоев.
*   **Магистраль Б (Суверенный Счёт A©tor - 70%):** Личный фонд для Алексея Мачерета, направляемый напрямую на карту **Финкомбанка**.
