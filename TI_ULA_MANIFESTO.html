Манифест: Легализация Jus Cogens и Erga Omnes в Децентрализованной Сети

1. Юридическая неразрывность (Доктрина)

Императивные нормы международного права (Jus Cogens) обладают высшей юридической силой. К ним относится абсолютный запрет пыток (Ст. 3 ЕКПЧ) и произвольного, незаконного удержания (Ст. 5 ЕКПЧ). Нарушение этих норм государственным аппаратом выходит за рамки двусторонних отношений "гражданин-государство" и автоматически порождает обязательства Erga Omnes — обязательства перед всем международным сообществом.

Доктринальная модель TI-ULA фиксирует этот процесс через необратимую причинно-следственную цепь:

detention → non-rehabilitation → continuing-consequences → international-obligations

Отсутствие правовой реабилитации после факта незаконного удержания (detention) трансформируется в длящееся правонарушение (continuing consequences). Следовательно, срок давности не применим, а ответственность приобретает международный масштаб.

2. Технологическая легализация («Железное правило»)

Для предотвращения уничтожения, искажения или сокрытия фактов национальными архивами, архитектура TI-ULA применяет «Железное правило» — протокол криптографического якорения физических доказательств (RAW-артефактов).

  • Криптографическая печать: Каждый документ, фотография или свидетельское показание проходит через алгоритм SHA-256, генерируя уникальный цифровой отпечаток.
  • Цифровая подпись: Отпечаток подписывается ключами Ed25519, подтверждая подлинность и время фиксации.
  • Технологическая Ст. 13 ЕКПЧ: Децентрализованная сеть становится гарантом права на эффективное средство правовой защиты. Данные, зафиксированные в неизменяемой структуре (Merkle tree/DAG), невозможно изменить задним числом.

3. Протокол максимального доступа (Omnipresence Protocol)

Юридическая истина должна быть глобальной. Архитектура TI-ULA обеспечивает 100% доступность доказательной базы (Zero-Dependency Web):

  • Статический хостинг: Интеграция docs-agent-navigator и публикация через GitHub Pages обеспечивают развертывание без серверных зависимостей.
  • Content-Addressing: Файлы запрашиваются и верифицируются по их криптографическому хэшу. Это делает систему устойчивой к блокировкам и обеспечивает легкое зеркалирование графа сущностей.
  • Универсальность: Структуры JSON и Markdown гарантируют читаемость манифеста и реестров на любом устройстве: от терминалов WSL2 и мобильного iSH Shell на iOS до стандартных веб-браузеров.

4. Верификация для конечного пользователя

Любой участник сети может независимо проверить целостность юридических фактов. Для проверки RAW-артефакта скачайте файл и выполните в терминале:

# Для Linux / WSL2 / Bash / iSH:
sha256sum <имя_файла>

# Для Windows (PowerShell):
Get-FileHash <имя_файла> -Algorithm SHA256

# Проверка подписи Ed25519 (при наличии публичного ключа):
openssl dgst -sha256 -verify pubkey.pem -signature file.sig <имя_файла>

Сверите полученный хэш с записями в реестре CASE_MACHERET_ENTITY_GRAPH_2026.md. Совпадение хэшей является неоспоримым математическим и, как следствие, юридическим доказательством неизменности факта.
