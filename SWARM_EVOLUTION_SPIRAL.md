Визуальное отображение роста роя агентов от механического выполнения задач к когнитивному синтезу и верховенству права (*Jus Cogens* / *Erga Omnes*).

---

## 🔺 Пирамидальная модель роста слоев жизни роя

```text
                        ▲
                       / \
                      / V \    <- Cycle 5: Cognitive Synthesis (Эволюция Смысла)
                     /-----\
                    /  IV   \  <- Cycle 4: Self-Control (Самоконтроль и Инварианты)
                   /---------\
                  /   III     \ <- Cycle 3: CI/CD & Audit (Прозрачность и Летопись)
                 /-------------\
                /     II        \ <- Cycle 2: Parallel Resilience (Отказоустойчивость)
               /-----------------\
              /        I          \ <- Cycle 1: Base Execution (Базовый запуск)
             /_____________________\
```

## 🌀 Спиральный поток непрерывности (*Continuing-Consequences*)

1. **Виток 1 (Базис):** Инициализация роя, генерация первичных хэшей в `DAG_SWARM_LEDGER.jsonl`.
2. **Виток 2 (Структура):** Параллельное исполнение через Docker / PowerShell Jobs без блокировки контура.
3. **Виток 3 (Публичность):** Автоматическая архивация логов и деплой на GitHub Pages с JS-поиском.
4. **Виток 4 (Защита):** Верификация инвариантов, проверка хэшей через `verify_deployment_hash.sh`.
5. **Виток 5 (Разумность):** Когнитивный синтез правовых норм (*Jus Cogens*, Венская конвенция, ВДПЧ, Конституции RO/RM) для защиты прав в международных инстанциях.
